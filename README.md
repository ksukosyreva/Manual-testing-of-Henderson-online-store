# Ручное тестирование интернет-магазина Henderson

Данный репозиторий содержит портфолио учебного проекта по ручному тестированию веб-приложения, выполненного в рамках курса «Тестировщик ПО» в Нетологии.

## Цель проекта
Проверка функциональности интернет-магазина (профиль пользователя, авторизация, карточка товара, фильтры), выявление дефектов бизнес-логики, UI/UX и анализ клиент-серверного взаимодействия.

## Инструменты
- **Тестирование:** Ручное функциональное тестирование, тест-дизайн (классы эквивалентности, граничные значения).
- **Инструменты:** Chrome DevTools (Network, Elements), Яндекс.Таблицы / Google Sheets, GitHub Issues (баг-трекинг).
- **Работа с API:** Postman, DevTools Network.

## Найденные дефекты (6 багов)
В ходе тестирования были выявлены и задокументированы дефекты, в том числе:
1. **Критические ошибки бизнес-логики:** неверный расчет скидок (цена со скидкой выше обычной).
2. **Дефекты UX/UI:** дублирование фильтров в каталоге, отсутствие структуры фильтров.
3. **Ошибки поиска:** выдача нерелевантных товаров по поисковому запросу.

## Тестирование API и DevTools
- С помощью Chrome DevTools проанализированы сетевые запросы на странице авторизации. Проверен ответ сервера (JSON) для эндпоинта `GetCountries` (получение масок и префиксов для номеров телефона).
- Проверено отображение вёрстки карточки товара при граничных значениях цены (от 1 руб. до 10 000 000 руб.) путем изменения данных через DevTools.
